# Library of Congress — National Screening Room Importer

- Official site: https://www.loc.gov/collections/national-screening-room/
- JSON API: https://www.loc.gov/apis/json-and-yaml/
- Legal report: `docs/SOURCE_VALIDATION_loc_national_screening_room.md`

Media is streamed from `tile.loc.gov`. Files are **not** re-hosted.

Environment: none (public JSON). Settings keys: `loc_collections`, `loc_batch_size`, `loc_page`, `loc_rate_delay_ms`, `loc_min_duration_seconds`.
